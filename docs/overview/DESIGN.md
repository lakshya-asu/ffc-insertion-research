# Project entry page

Reading this as a research briefing for lab colleagues: an editorial guide to actual evidence, hardware decisions and the remaining work.

Preserve the existing static Pages stack, self-hosted IBM Plex Sans/Mono, green accent and light/dark tokens. Design variance 5, motion intensity 2, density 5. Native HTML/CSS/JavaScript; no new framework or runtime CDN. Engineering diagrams and actual recorded images have evidentiary value; generated imagery would misrepresent the work.

Audit: the old root is a narrow historical-video archive with system fonts and an outdated 17-test banner. Its first claim describes privileged-state generic insertion, ahead of the much newer sensor-first work. Other pages already have stronger editorial styling but lack a current central narrative. Preserve those pages and their anchors; archive the root at experiments.html and forward its known legacy hashes. The user explicitly requested new information architecture connecting the existing pages.

The hero introduces the task and actual cell. A presenter route leads into an evidence player, a hardware/cell explorer, the held-out perception inspector, the ROS/control boundary, seven skill gates and a research library. Status language distinguishes implemented software, isolated physics, historical experiments and planned capabilities. Content is readable without JavaScript; enhanced controls are hidden until initialized. Images reserve dimensions, videos load on request, errors retain direct artifact links. No scrolling animations or automatic video playback.

Layer scale: normal content 0, sticky navigation 10, skip link 20. Sharp geometry with a 4px control radius throughout. Shared auto/light/dark theme. Class-label colors are data encodings, not additional brand accents.

Review requires desktop/mobile screenshots, theme and keyboard controls, the media choices, all 60 review frames, missing-manifest handling, local links, media metadata, axe and Lighthouse. These checks validate the website, not insertion physics.
